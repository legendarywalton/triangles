# Isosceles and right triangles

An animated walkthrough of what separates isosceles triangles (classified by sides) from right triangles (classified by angles), and where the two overlap.

Nine scenes: classification, Base Angles Theorem and its converse, the Triangle Longer Side Theorem, legs and hypotenuse, the Pythagorean Theorem, Hypotenuse-Leg, the 45-45-90 triangle, and a draggable model.

Single self-contained `index.html`. No build step. Open it locally or serve it with GitHub Pages.
